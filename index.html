Catches the profiles a client has already told us they don't want, before the email goes out, and turns free-text rejection feedback into structured reasons. Built for The Date Crew Product Engineer assessment. This page runs the repo's tested Python in your browser on mock data calibrated to the brief.

Structured reasons

avoidable the profile broke a preference the client already gave us. The pre-send check catches these.

preference gap a reason the form covers, but the profile didn't break it, so the client's stated preferences are out of date.

unstated something the form doesn't capture yet (looks, personality, career). These show what to add to the form next.

The prototype uses a keyword classifier so it runs offline and is fully testable. In production an LLM would return the same taxonomy as JSON, with this version kept as the baseline in the eval set.
