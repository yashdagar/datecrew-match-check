Structured reasons

avoidableThe profile broke a preference the client already gave us. The pre-send check would have caught it.
preference gapA reason the form covers, but this profile didn't break it, so the client's stated preferences are out of date.
unstatedSomething the form doesn't capture yet, like looks, personality or career. These show what to add next.

The prototype uses a keyword classifier so it works offline and is fully tested. In production an LLM would return the same reasons as JSON, with this version kept as the baseline in its eval set.
